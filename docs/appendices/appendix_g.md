# 附录G：Kaggle 评估指标速查（含“Agent 容易在哪个指标上骗你”的提示）

> 不同比赛用不同指标，选错指标 = 优错方向。本附录列常用指标、含义、适用场景，以及 Agent 最容易在哪个指标上“骗你”。

---

## G.1 常用指标速查

| 指标 | 公式/含义 | 适用场景 | 方向 |
|------|-----------|----------|------|
| AUC | ROC 曲线下面积 | 二分类分数 | 越大越好 |
| LogLoss | 交叉熵，惩罚过度自信 | 二分类概率 | 越小越好 |
| RMSE | 均方根误差 | 回归 | 越小越好 |
| MAE | 平均绝对误差 | 回归，对异常值不敏感 | 越小越好 |
| MAPE | 平均绝对百分比误差 | 时序/销量预测 | 越小越好 |
| Accuracy | 准确率 | 平衡分类 | 越大越好（极不平衡慎用） |
| F1 | 精确率与召回率调和平均 | 不平衡分类 | 越大越好 |

---

## G.2 “Agent 容易在哪个指标上骗你”

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 用准确率做不平衡 | 全预测负类也 99% 分 | 用 AUC / F1 |
| 用 LogLoss 忽略校准 | 概率不准但分类分高 | 做可靠性曲线 + Isotonic 校准 |
| RMSE 被极端值主导 | 一两个离群点拉爆分数 | 用 MAE 或 RMSPE |
| AUC 不关心概率校准 | 概率都挤在 0.1-0.9 | 配合 LogLoss 或校准检查 |
| Public LB 噪声大 | 样本少，分数虚高 | 本地 CV 为主，LB 为辅 |

**最核心的一条**：指标不是随便换的，指标决定了优化方向。Agent 会优化你给它的指标，如果指标选错了，它会很“努力”地往错的方向努力。
